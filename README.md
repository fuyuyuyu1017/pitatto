# ぴたっと

広がっていく円をタップで止めて、目標の輪にぴったり重ねるタイミングゲームです。5ラウンドで、ラウンドごとに円が速くなります。

## 遊び方

- 画面のどこかをタップすると円が止まります（パソコンではスペースキーでも可）
- 輪とのずれが小さいほど高得点です（PERFECT 100点 / GREAT 70点 / GOOD 40点）
